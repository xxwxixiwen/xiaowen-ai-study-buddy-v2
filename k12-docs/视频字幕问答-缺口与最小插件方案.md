# 视频字幕问答：现状、缺口与最小插件方案

## 现状（已实现，零代码）
- `scripts/k12/srt_to_md.py` 把 SRT 转成每行带 `[分:秒–分:秒]` 的 Markdown 字幕时间轴（`k12-content/generated/`）。
- 字幕时间轴 + 讲稿建成知识库 `xiaowen-video`；小文 Persona 规定“回答视频问题必须标注时间点、只能取自字幕行”。
- 结果：问“补 0 在哪段讲的”→ 回答“视频 02:36–03:04”，并逐条对应字幕。

## 原生能力（有真实视频时直接用，无需插件）
| 来源 | 时间轴 | 播放 + 点击时间点跳回 |
| --- | --- | --- |
| YouTube / B 站链接（Reading → 添加链接） | 平台字幕 | 原生支持 |
| 上传 mp4 / mp3（Reading 上传） | 需在 设置 → 语音 配置转写模型（STT） | 原生支持 |
| 只有本地 SRT、没有视频文件 | 不支持导入 | **缺口** |

`immersive_reading` 对带时间轴的媒体会按时间点引用并可跳转，所以拿到真实视频后，上传视频并配置 STT 即可，本方案的插件不再需要。

## 缺口
1. 本地 SRT 无法作为“带时间轴的媒体”导入 Reading，只能走知识库文本检索。
2. 知识库回答里的时间点是纯文本，不能点击跳回播放位置（也没有可播放的视频）。

## 最小插件方案（不实现，仅设计）
仿照 `examples/plugins/learning_echo/`，独立包 `xiaowen_video`：

```json
{
  "schema_version": "deeptutor.plugin/v1",
  "id": "org.xiaowen.video_player",
  "permissions": { "ui": ["sandboxed-iframe"], "storage": ["plugin"] },
  "extensions": [
    { "type": "http_route", "id": "srt", "entry_point": "xiaowen_video.worker",
      "path": "/srt", "methods": ["POST", "GET"], "auth": "authenticated" },
    { "type": "frontend_page", "id": "player", "path": "/xiaowen-video",
      "auth": "authenticated", "manifest": "frontend/page.json" }
  ]
}
```

- `worker.py`（stdin/stdout JSON 协议，不 import 宿主）：`POST /srt` 接收 SRT 文本与视频 URL，解析为 `[{start, end, text}]` 存插件私有存储；`GET /srt` 返回 cue 列表。
- 前端页（沙箱 iframe）：`<video>` 播放器 + 字幕列表；把文本中的 `02:36` / `02:36–03:04` 正则识别为链接，点击执行 `video.currentTime = 156`；URL 支持 `#t=156` 深链，便于从对话里的时间点跳过来。
- 对话侧不改核心：Persona 已统一输出 `（视频 分:秒）`，插件页可把同一格式渲染成跳转链接。
- 估算：约 150 行 Python + 200 行前端；`deeptutor plugin build/install/enable` 审批后可用，可随时 `rollback`。

## 替换为真实课程视频
1. 首选：Reading 上传 mp4（或填 B 站/YouTube 链接），在 设置 → 语音 配好 STT，直接用原生沉浸阅读。
2. 只有字幕时：`srt_to_md.py 新字幕.srt k12-content/generated/xxx.md`，再 `deeptutor kb add xiaowen-video --doc k12-content/generated/xxx.md`。
